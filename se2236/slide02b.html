Core Definition & Proof Strategy Map

Formal Big-O Definition: $f(x)$ is $O(g(x))$ iff there exist positive constants $C$ and $k$ (or $c, n_0$) such that $$f(x) \le C g(x) \quad \forall x > k.$$

Binomial Power Bound Prep for 1a: R-3.17

Worked Example 2: Show that $(n + 2)^4$ is $O(n^4)$ using the definition of Big-O.

Method A: Direct Base Bounding

  1. Choose threshold $n_0 = 1$ (so $n \ge 1$).
  2. Since $2 \le 2n$ for all $n \ge 1$: $$n + 2 \le n + 2n = 3n$$
  3. Raise both positive sides to the 4th power: $$(n + 2)^4 \le (3n)^4 = 81n^4$$
  4. Witnesses: $c = 81,\; n_0 = 1$.

Method B: Binomial Expansion

  1. Expand $(n + 2)^4$: $$n^4 + 8n^3 + 24n^2 + 32n + 16$$
  2. For $n \ge 1$, replace every $n^k$ ($k < 4$) with $n^4$: $$\le (1 + 8 + 24 + 32 + 16)n^4$$
  3. Sum the coefficients: $$(n + 2)^4 \le 81n^4$$
  4. Witnesses: $c = 81,\; n_0 = 1$.
Takeaway for R-3.17: Both methods yield identical witnesses; Method A avoids expanding high powers.

Polynomial Big-O Witnesses Prep for 1b: #3

Worked Example 3: Use the definition of "$f(x)$ is $O(g(x))$" to show that $f(x) = 2x^3 + 7x^2 + 5x + 11$ is $O(x^3)$.
  1. Set the threshold $k$: Assume $x > 1$ (so $k = 1$).
  2. Establish term-by-term inequalities for $x > 1$: $$1 < x < x^2 < x^3$$
  3. Bound the entire polynomial from above by multiples of $x^3$: $$ \begin{aligned} 2x^3 + 7x^2 + 5x + 11 < 2x^3 + 7x^3 + 5x^3 + 11x^3 &= (2 + 7 + 5 + 11)x^3 = 25x^3 \end{aligned}$$
  4. Verify the definition: For all $x > 1$, $|f(x)| \le 25|x^3|$.
Witnesses: $C = 25$ and $k = 1$. Therefore, $2x^3 + 7x^2 + 5x + 11$ is $O(x^3)$.

Exponential Base Domination Prep for 1b: #4

Worked Example 4: Use the definition of "$f(x)$ is $O(g(x))$" to show that $f(x) = 3^x + 25$ is $O(4^x)$.
  1. Choose a threshold $k$ where $3^x$ dominates the constant $25$:
    • Test $x = 3$: $3^3 = 27 > 25$. So for all $x > 3$, we have $25 < 3^x$.
  2. Combine the terms into a single exponential: $$3^x + 25 < 3^x + 3^x = 2 \cdot 3^x \quad \forall x > 3$$
  3. Step up the exponential base from $3^x$ to $4^x$:
    • Since $3 < 4$ and $x > 3 > 0$, we know $3^x < 4^x$. Thus:
    $$3^x + 25 < 2 \cdot 3^x < 2 \cdot 4^x \quad \forall x > 3$$
Witnesses: $C = 2$ and $k = 3$ (alternatively, $C = 26, k = 1$ since $25 < 25 \cdot 3^x$ for $x > 1$).

Finding the Least Integer $n$ for $O(x^n)$ Prep for 1b: #7

Worked Example 5: Find the least integer $n$ such that $f(x)$ is $O(x^n)$ for each function.

(a) $f(x) = 5x^2 + x\log x$

For $x > 1$, $\log x < x \implies x\log x < x^2$.

$f(x) < 5x^2 + x^2 = 6x^2$.

Least integer: $n = 2$

(b) $f(x) = 4x^2 + (\log x)^5$

Any polylog $(\log x)^a$ grows slower than $x^b$ ($b > 0$), so $(\log x)^5 = O(x)$.

$4x^2$ dominates. Least integer: $n = 2$

(c) $f(x) = \dfrac{x^5 + 3x^2 + 1}{x^2 + 1}$

For $x > 1$: numerator $< 5x^5$, denominator $> x^2$.

$f(x) < \dfrac{5x^5}{x^2} = 5x^3$. Least integer: $n = 3$

(d) $f(x) = \dfrac{x^3 + 7\log x}{x^3 + 1}$

For $x > 1$: numerator $< 8x^3$, denominator $> x^3$.

$f(x) < \dfrac{8x^3}{x^3} = 8 = 8x^0$. Least integer: $n = 0$

Strict Growth & Proof by Contradiction Prep for 1b: #9

Worked Example 6: Show that $x^3 + 5x + 9$ is $O(x^4)$, but $x^4$ is not $O(x^3 + 5x + 9)$.

Part 1: Prove $x^3 + 5x + 9$ is $O(x^4)$

  1. Assume $x > 1$.
  2. Bound every term by $x^4$: $$x^3 + 5x + 9 < x^4 + 5x^4 + 9x^4 = 15x^4$$
  3. Witnesses: $C = 15,\; k = 1$.
  4. Hence $x^3 + 5x + 9 = O(x^4)$.

Part 2: Prove $x^4 \neq O(x^3 + 5x + 9)$

  1. Suppose for contradiction that $\exists\, C, k > 0$ such that for all $x > k$: $$x^4 \le C(x^3 + 5x + 9)$$
  2. For $x > k$, $x^3 + 5x + 9 < 15x^3$: $$x^4 < 15C x^3 \implies x < 15C$$
  3. Contradiction: Fails whenever $x > 15C$.

Quick Checklist Before Writing Solutions

  • Always state both witnesses explicitly: A Big-O proof is incomplete unless you name concrete values for $C$ and $k$ (or $c$ and $n_0$) and verify $x > k$.
  • Fractional bounding direction: To bound $\frac{N(x)}{D(x)}$ from above, make the numerator larger ($N(x) \le \dots$) and the denominator smaller ($D(x) \ge \dots > 0$).
  • Watch out for $n = 0$ in Exercise 7: When numerator and denominator have the same degree (e.g., $\frac{x^4 + \dots}{x^4 + 1}$), the function is bounded by a constant $C = C \cdot x^0$, so the least integer is $n = 0$.
  • Disproving Big-O (Exercise 9): Always assume $f(x) \le C \cdot g(x)$ holds for all $x > k$, divide out the highest common power, and derive an impossible upper bound on $x$ (like $x \le \text{constant}$).
